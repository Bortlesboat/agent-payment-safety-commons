# Base Builder Rewards / Grants Note

## Positioning

Agent Payment Safety Commons is public-good infrastructure for Base builders using x402-style USDC payments.

Base's current funding docs emphasize:

- weekly rewards for prototypes and experiments
- retroactive Builder Grants for shipped projects
- public goods and ecosystem infrastructure as strong fits

This repo should be positioned as:

> Safety infrastructure for AI agents spending USDC on Base through x402/MPP-style paid APIs.

## Why Base Should Care

Base can become the default settlement layer for agent-to-API payments. That only works if builders and users trust autonomous spend. This project helps by giving Base developers reusable checks before they connect real wallets.

## What To Ship Before Applying

- Public repo with tests passing
- Base-specific fixture using USDC-on-Base payment metadata
- Demo video or screenshot of `npm test` and `npm run check`
- Short README section: "For Base/x402 builders"
- Optional Base mainnet or testnet dry-run demo if safe and low-cost

## Evidence To Attach

- GitHub repo
- safety report artifact
- existing x402 payment experience and production Satoshi API receipts
- public docs explaining spend limits, receipt binding, and replay protection

## Ask

Start with Builder Rewards / Builder Score visibility, then apply for retroactive Builder Grant once the repo has public commits and at least one Base-specific demo.
